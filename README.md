# react-template
The simple react template site

## How to use?
1. Clone this repository
2. Run `pnpm install` to install dependencies
3. Change `index.html` and `src/lib/projectConfig.ts` to your choice
4. Run `pnpm dev` to start!

## Technology
- React
- Vite
- TypeScript
- Cloudflare(wrangler)
- Tailwind CSS
- shadcn/ui(Radix UI)
- Tanstack Router
- Paraglide js
- Zod
- usehooks-ts
